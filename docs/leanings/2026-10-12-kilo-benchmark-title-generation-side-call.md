# 2026-10-12 — Kilo benchmark title generation is a separate model call

- **Status:** Resolved for certified preflight; full four-task comparison remains in progress.
- **Task/context:** Certified P/Pi/Kilo comparison on the same local model, using the real Kilo 7.7.5 CLI and the bounded egress proxy.
- **Symptom/evidence:** Two consecutive live runs passed Kilo startup and P/Pi instruction parity but failed Kilo parity with two proxy requests and one rejected completion. The first run reported a generic `forward-error`; a payload-free transport diagnostic in the second identified `client-disconnect`. Kilo exited successfully after emitting `step_start`, `text`, and `step_finish`, so successful CLI exit alone did not establish complete proxy evidence.
- **Root cause:** Kilo creates a separate model request to generate a default session title. Its title path is skipped for a non-default title, while the certified proxy requires a successful model-bearing response for every completion request. The cancelled side request therefore invalidated certification despite the main answer succeeding.
- **Approaches tried:** Increasing the Kilo startup allowance did not address this parity failure. The proxy diagnostic first narrowed the failure without logging exception text or request payloads. Passing a stable `--title "P benchmark"` to Kilo's real `run` command then allowed the live Kilo instruction-parity preflight to finish and the first scored task to start.
- **Resolution:** Supply the fixed non-default title for startup, parity, scored, and continued Kilo runs; preserve the original prompt as the final CLI argument. Keep proxy rejection of incomplete/cancelled requests rather than weakening model evidence.
- **Verification:** `benchmarks/test/workloads/kilo-session-title.test.ts` checks probe, new-task, and continued commands. `benchmarks/test/harness/certified-proxy-transport-diagnostics.test.ts` checks a real upstream socket reset, a 502 with empty body, and payload-free rejection classification. The benchmark suite and full `./test.sh` passed; the live certified run passed all three instruction preflights and entered scoring. This is not yet a certified 36-cell result.
- **Prevention/follow-up:** When integrating another CLI, account for auxiliary model calls as well as visible responses. Require independent wire evidence for every request, and isolate or explicitly suppress non-task model calls before claiming same-model parity.
